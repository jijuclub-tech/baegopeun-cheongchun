## 광고 의뢰

100p는 쪽수가 아니다. 사용자가 광고를 의뢰할 때 지불하는 포인트다. 의뢰 1건 = 100p.

1. AI로 초안을 만든다.
2. 의미를 잠근다. 여기서 의뢰가 성립한다.
3. 그 문장의 형태만 바꾼다. 같은 100p다.

의미를 바꾸면 새 의뢰, 다시 100p. 형태만 추가하면 10p.

판매가는 예스24 페이지 기준이다. 정가 33,300원, 판매가 29,970원(10% 할인)은 2026-10-08 확인값이다.
